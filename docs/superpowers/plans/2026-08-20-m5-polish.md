# M5「好检索好迁移」+ UI 大修 实施计划

> 前置阅读：DESIGN §12 M5、§9（检索）、§4.3（标签过滤补充）、用户裁定记录（roadmap：预算移除、UI 大修首要、完工统一验收）。授权直接执行。

**任务：**

1. **UI 大修（首要，用户裁定）**：全局字号/间距/图标放大对齐 `prototype/css/style.css` 视觉基调——基础正文 14–15px、侧栏条目 13→14px、工具条/菜单按钮加大（px-3 py-1.5、字号 13px）、图标（emoji）15→17px；三栏留白与卡片间距放宽；标题栏/横幅高度略增。逐组件过一遍（AppShell/PostTree/KbTree/EditorPane 工具条/右栏页签/各 Dialog），保持设计令牌不变、只调尺度与密度。jsdom 无像素断言——以类名/结构回归测试保底 + 人工验收。
2. **全局搜索 UI（§9）**：`search_all(query, include_versions)` 命令（Scope 扩展 All：posts+materials；include_versions 再并入 publish 行）；左栏「🔍 全局搜索」入口 → 覆盖层（Ctrl+Shift+F）：输入 + 分组结果（文稿/资料/发布版本），点击跳转对应视图；高亮命中词（title/snippet）。文稿列表**标签过滤**（§4.3 尾欠）：PostTree 过滤器加标签下拉。
3. **Markdown 导出/导入（§12）**：`export_md(scope: posts|kb, dest_dir)`——保留目录结构（posts 平铺+kb 树）、frontmatter 原样拷贝、**附件随行**（把引用到的 `_assets` 文件拷到导出根 `_assets/`，正文相对路径按导出布局重写）；导入复用既有（kb 导入已有；posts 外部 md 走 pending_import）。UI：设置区「导出…」按钮（tauri dialog 选目录）。
4. **单文稿打包导出（§12）**：`export_post_zip(post_id, dest_path)`——zip 含 `post.md`（正文相对引用重写为包内 `_assets/`）+ `post.md.history/` + `publish/*.md`（同样重写引用）；zip crate（`zip = "2"`，deflate）。UI：文稿右键「打包导出…」（dialog 存路径）。
5. **忽略规则完善（§12）**：扫描器排除工作区内 `.git/`、`node_modules/`（kb 树/扫描健壮性）；孤儿附件清单已具备（M3）——补一个「全工作区引用计数」列。
6. **收尾验收**：cargo + vitest + tsc 全绿；`pnpm tauri build` 出包（**唯一一次**，测试全绿后）；QA 清单 + roadmap 收口 + 统一验收摘要（M4+M5 一并）。

**测试要点**：search_all 范围与分组；导出往返（导出→目录结构/附件/重写链接断言）；zip 包内容与引用重写；扫描排除规则；标签过滤；UI 组件回归。
